# Control+Z - Blog para aprender GitHub (Proyecto WordPress)

Este blog en WordPress ha sido creado como proyecto personal para **aprender a utilizar WordPress como CMS**, usando el tema Astra y un tema hijo personalizado. El contenido del blog está centrado en **tutoriales y recursos de GitHub para principiantes**.

## Descripción general del proyecto
- La mayor parte de la personalización se realizó **directamente desde el tema Astra y el personalizador de WordPress** (colores, tipografías, diseños, menús, widgets, etc.).
- Se añadieron algunos estilos y efectos adicionales mediante CSS personalizado.
- Se implementó una integración con la API de GitHub para mostrar mis repositorios en la página "Sobre mí".
- Desplegado en InfinityFree con el plan gratis.

## Características
- Tutoriales y guías de GitHub para principiantes.
- Tema hijo personalizado basado en Astra.
- Diseño simple y responsive.
- Visualización de repositorios de GitHub en la página de “Sobre mí”.
- Pequeños ajustes visuales adicionales mediante CSS.

## Qué es este repositorio (y qué no es)
✔️ Muestra la estructura del tema hijo y parte del código personalizado  
✔️ Incluye CSS personalizado y la funcionalidad de la API de GitHub  
❌ NO incluye la base de datos de WordPress, archivos multimedia ni plugins  
❌ NO está pensado para recrear completamente la web instalando el tema

⚠️ ***Nota: La mayoría de la configuración del blog, las entradas y los medios están almacenados en la base de datos de WordPress. Instalar únicamente el tema hijo **no replicará el contenido completo del blog**. Este repositorio muestra principalmente el tema personalizado, los estilos y la integración con la API.***
